# SLE-3: Architectural Design Using Full C4 Model

## Maze Solving System Using BFS and DFS

This project implements a maze/graph search from node **A** to goal node **J** using Breadth-First Search (BFS) and Depth-First Search (DFS).

### Run
```bash
python bfs_dfs.py
```
